Sass Customization Demo

How Bootstrap Sass customization works

Bootstrap Sass customization happens before compilation. You override variables such as the primary color or border radius in a custom Sass entry file, then rebuild Bootstrap with your theme values.

In a larger project, this is how you create a branded design system without rewriting the framework from scratch.

$primary: #0b5ed7;
$border-radius: 1rem;

@import "bootstrap/scss/bootstrap";
